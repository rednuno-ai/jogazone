Campo Minado

Minas: 15
Clica para revelar. Botão direito para marcar.

Como jogar

Clica numa célula para a revelares. Os números indicam quantas minas há nas células vizinhas. Usa o botão direito do rato para marcares uma célula suspeita com uma bandeira. Revela todas as células sem minas para venceres.
