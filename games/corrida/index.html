Corrida a Dois

Prontos... Partida!

Como jogar

Jogador 1 (vermelho): W / A / S / D para acelerar, travar e virar.
Jogador 2 (azul): setas do teclado.

Evita bater nas paredes vermelhas — perdes velocidade. Chega primeiro à bandeirinha axadrezada para venceres a corrida.

Física de condução adaptada do projeto open-source js-Racing de Gaëtan Blaise-Cazalet, licença MIT. Gráficos redesenhados de raiz para o JogaZone.
