O Jogo Impossível

Tentativas: 0
Checkpoint: 0 / 4
Chega ao topo sem tocar nas bolas.

Como jogar

Usa as setas do teclado para mover o quadrado vermelho pelos corredores, evitando as bolas em movimento. Cada linha branca que atravessas é um checkpoint — se fores atingido, voltas ao último checkpoint em vez de recomeçares tudo. Chega à faixa dourada no topo para venceres.
